## Android 测试版

当前为 **Android 0.1.0 测试版**，要求 **Android 8.0 及以上系统**，暂无 iOS 版本。APK 按架构分为 `arm64-v8a`、`armeabi-v7a`、`x86_64`、`x86` 与包含全部四种架构的 `universal` 通用包，均可独立安装；现阶段实机测试集中在 **ARM64 手机**。[源码与编译说明](../android/README.md)

- **权限与数据备份**：相机权限用于拍摄和实景透射观片；后台冲洗使用前台服务与通知；旧版 Android 导出至系统相册可能需要存储权限。应用内胶卷与底片不随系统自动备份，换机或卸载前请主动导出重要资源。
- **采集格式支持**：
  - **JPEG**：常规采集入口，经标准 sRGB 逆转换进入线性工作空间。
  - **RAW（DNG）**：支持未压缩 8 / 16 位 Bayer DNG 与三通道交错 LinearRaw DNG（Bayer 按有效区解马赛克，LinearRaw 直接读取三通道），均按相机标定转入线性工作 RGB。
  - **Ultra HDR**：需 Android 14+、兼容 sRGB 基图与真实增益图，具体可选格式取决于设备。压缩 DNG 与广色域 P3 暂未完整支持；16 位扫描输出仍为 SDR 成片。

## 从装卷到成片

1. **装卷**：在拍摄首页选择材料、135 / 半格 / 120 画幅、卷长并完成装填（命名、搭配、采集精度与退卷选项收在“更多装卷设置”中）。
2. **拍摄**：进入横屏取景器，点击对焦测光、双指缩放、调节 EV 后按快门；未拍完可随时退出，下次继续同一卷。
3. **封卷**：在拍摄页菜单执行封卷，胶卷进入胶卷库待冲洗。
4. **冲洗**：在胶卷库打开该卷，套用推荐工艺或进入 **自由冲洗台** 自定义药浴。
5. **观片与扫描**：打开冲洗结果，用灯台观看或进入扫描调整风格、光源、色彩与曲线，点击保存生成照片。

## 拍摄操控

| 操作 | 用法 |
| --- | --- |
| 手动过片 | 拍完一格后快门锁定，点击“过片”进入下一格 |
| 多重曝光 | 点击“多曝”重新上弦，在当前格叠加曝光 |
| 自动过片 | 在相机设置中开启，保存后自动过片；拍摄页提供快捷切换 |
| EV 与倍率 | 短按滑钮后拖动（侧栏上下、底栏左右）；双击复位 |
| 135 宽幅 | 为 135 上下加入未曝光挡片；未过片时可切换，每次曝光独立保留状态 |
| 镜头与闪光 | 在拍摄页按设备能力切换镜头、倍率与闪光模式 |
| 采集格式 | 静照取景时点底栏当前的 JPEG / RAW / HDR 切换下一次曝光格式，待相机就绪后拍摄 |

### 首页分区与装卷设置

- 拍摄首页分为 **当前在机胶卷**、**机身与拍摄设置** 与 **下一卷默认设置**。当前卷显示装填时锁定的材料、画幅、卷长与进度；**感光度与快门**独立控制后续拍摄的传感器曝光；下一卷默认设置（颗粒、老化、MTF 柔化、光晕、齿孔与厂印边字）只在真正装卷时冻结进新卷，不影响已在机胶卷。
- 装卷弹窗会直接汇总下一卷的颗粒、老化与片边摘要，点 **微调颗粒／老化／片边…** 调整后返回不丢失当前选材与画幅。
- 横屏取景教程会按当前可用按钮就地高亮提示；点取景器上方 **?** 可随时重开。

### 相机效果与文字打印

- **相机效果**：在相机设置中按 **漏光 / 片门 / 打印** 分页配置，上方固定样张并汇总已开启项目。漏光最多支持 8 个独立分量（分别控制形态、方向与强度，单分量归零保留位置）；灰尘、碎屑、毛发、飞虫与文字打印可自由叠加。保存后仅作用于后续曝光。
- **文字打印**：支持最多 **24 个大小写英文字母、数字、空格与英文标点**（全角英文自动转半角，不支持中文与表情；留空即关闭）。纯日期沿用传统数字字形，含字母或其它标点时整串切换 5×7 点阵字形。亮度范围 0–200%（100% 为基准），支持四角预设与水平/垂直滑杆定位。
- **颗粒、MTF 与光晕**：在装卷前选择强度（“自然”沿用材料基准，“关闭”同时关闭染料颗粒与银粒）；新卷采用细颗粒加粗染料云的层间部分相关纹理，药浴条件仍会影响颗粒幅度、尺度与聚集。

## 冲洗与配方

### 准备页与方案选择

- 打开待冲胶卷默认进入 **准备** 页：先看清“本卷材料 → 实际工艺 → 预期底片与工序顺序”，再决定本次仅保留底片还是同时生成图库照片，最后点击底部 **开始**（未完成任务会自动识别续跑）。
- 在 **选择冲洗方案** 中，可按推荐、工艺、药液风格、我的配方横向滑动切换分类，点选一行采用。
- 顶部标签可直达 **药浴条件**、**冲洗事故**、**追加片基漂白** 与 **扫描与保存**。在准备页、自由冲洗台与单浴编辑中均提供实时**合成工艺样张**，直观呈现当前草稿的成像趋势。
- 彩片走黑白工艺会标记为银像并保留原片基与残盐；无染料层的黑白材料若选完整彩色工艺，系统会提示银漂白可能清空影像并提供一键切至彩色留银工艺。

### 自由冲洗台与多因素事故

- **自由冲洗台**：以基础药浴顺序为主页，横向切换 **共用药液与条件 / 共用摇晃 / 共用反应 / 邻接与 DIR**；点选任一药浴可查看继承值或单独覆盖条件（主冲洗页的“共用药浴时长”作用于未设独立时长的药浴，非总时长）。单浴点 **完成** 仅更新工作台草稿，外层点 **应用到本次冲洗** 才带回准备页；离开时若有未应用修改会弹窗确认。
- **手机摇晃记录**：支持通过陀螺仪采集摇晃动作，也可手动输入。同一卷可反复创建多个独立冲洗批次。
- **冲洗事故与片基漂白**：两者独立管理。显影不匀、化学污斑与乳剂网裂各自支持 **沿用 / 关闭 / 指定强度**，并支持 24 步会话内撤销/重做（连续拖动合并为一步）；“干净冲洗”仅关闭这三类事故，不影响颗粒与其他材料设置。
- **配方复用**：材料、药浴与扫描预设在设置页独立管理，可通过 **FFC2 分享码** 复制或导入；已装胶卷与既有任务沿用各自冻结的配置。

## 观片与扫描

| 方式 | 呈现方式 |
| --- | --- |
| 灯台 | 按底片原有正负极性观看，点“灯光”调节亮度与色温 |
| 实景透射 | 将透明底片叠加在实时相机取景上，支持缩放、拖动与复位 |
| 正像投射 | 将底片解释为正像直接观看 |
| 扫描 | 调整风格、去片基/反相、光源、色彩与曲线后保存为图库照片 |

> **只读原则**：扫描与观片只读取已形成的光学底片，绝不回写冲洗结果。冲洗完成页与底片批次页均提供一键扫描单张或整批入口。

### 扫描抽屉、工具与触控

- **预览优先的调整抽屉**：进入扫描默认显示大图；点按或上滑底部 **扫描调整** 展开抽屉，拖动顶部手柄可自由停靠高度（始终为预览保留至少 1/5 空间）。
- **工具顺序**：底部依次为 **底片（去片基 / 反相） → 光源（曝光 / 色温） → 明暗（扫描增益 / 对比度） → 归一化 → 色彩 → 曲线 → 输出 → 更多**。在工具正文区域左右滑可切页，上下滑浏览内容。
- **去片基与反相开关**：系统按最终底片的实际极性与色罩给出初始推荐（负片双开、中性正片双关、强色罩正片去罩不反相），随时可手动覆盖或点 **恢复自动匹配**。同片切换扫描风格会保留这两个开关；在「底片」页还可展开当前冲洗配方的**工艺样张**跨工具对照。
- **精细触控**：点按或拖动滑钮直接定位；长按出现 **精调** 后左右微调（大量程参数每格仅变动一个最小单位）；带数值按钮的参数可点按精确输入；双击扫描增益或刻度恢复继承值，双击 HSL 刻度归零当前色区该项。
- **光源曝光方向与归一化**：新版手机扫描先在中性曝光下完成片基与黑白场定标，再施加光源 EV（反相开启时 EV 降低变亮、关闭时升高变亮）；「明暗」中的扫描增益始终同向调亮。默认负片扫描先经 `sigmoid` 收住高光再归一化，避免调低归一化强度时混回溢出读数。
- **曲线与分色 HSL**：「色彩」页横滑选色区直接在预览下方调 HSL；「曲线」页点黑白/红/绿/蓝圆点切换通道，双击加点、拖动调整或点坐标精确输入。风格名称会在修改风格参数后标出 `· 自定义`，长按可查看改动项。

### 会话、历史与直方图

- **预览复用与对照**：调节灯光复用同片未照明透射读数，减少重复遍历；切到后台返回会保留已完成预览与保存回执。长按扫描照片可即时对照本次进入时的初始预览及直方图，松手回到当前效果。
- **顶栏与独立会话**：顶部提供返回、画面旋转、直方图叠层开关、撤销/重做与保存（连续拖动、曲线编辑或组复位各计一步，进程内最多保留 8 个会话 × 24 步历史）。在已保存照片菜单中，**继续调整这张照片** 还原其冻结参数与原扫描实现；**从来源底片开始扫描** 则新开独立会话。
- **保存与系统相册**：单张点 **保存** 直接存入软件图库并留在编辑页，便于查看、继续调色或切到本批下一张；重复同参数会提示复用，保留旧版本。需要同步导出系统相册或批量扫描，在 **输出** 页配置。

### 计算与 GPU 协同

- 在 **设置 → 后置处理 → 计算与加速** 可开关 **GPU 协同计算（自动择优）**（默认开启，下次任务生效）。符合校验与含传输耗时条件的线性化、透射、光谱积分、轻量连续药浴及扫描输出可走 OpenGL ES 3.1，不可用或失败自动回退 CPU。
- 潜影与底片归档默认采用快速无损压缩；**最近运行记录** 分阶段展示最近任务累计耗时与实际后端（硬件自测仅反映合成块速度，不代表整张冲洗耗时）。

## 胶卷库与图库

底部四个主标签为 **拍摄 / 胶卷库 / 图库 / 设置**：

| 资源层 | 管理方式 | 后续用途 |
| --- | --- | --- |
| 曝光胶卷（原片与潜影） | 按整卷管理 | 反复以不同工艺重新冲洗 |
| 冲洗底片 | 单张或按批次管理 | 观片、重新扫描、导出 NPZ |
| 扫描照片 | 单张或批量管理 | 浏览、评级收藏、导出与溯源 |

- **三层独立保存**：删除某一层不会自动删除另外两层（删卷将无法再重冲，已有底片与照片保留；删底片将失去重扫入口，原卷与照片保留）。
- **视图、筛选与观片缓存**：图库支持三列、五列与详细列表切换，支持按创建时间/文件大小/卷名排序，按胶卷、仅收藏及评级条件筛选，并支持翻页或连续滑动浏览（放大照片拖至边缘继续滑动即可翻页）。底片放大时在后台按内存预算逐行加载高清细节，已生成的灯台/投射图会进入独立显示缓存（可在 **后置处理 → 显示缓存** 清理）。
- **参数复位（↺）**：参数旁的 **↺** 恢复该项预设或继承值；扫描各组 **↺** 只重置本组；曲线「预设曲线」恢复风格曲线，通道 **↺** 恢复直线；灯台复位至 `0 EV / 5500 K`。

## 保存与导出

### 格式与精度边界

- **JPG**：8 位有损，提供低 / 中 / 高三档（40 / 70 / 100），可直接导出至系统相册（未旋转时直接复制原件）。
- **PNG**：8 / 16 位无损，支持系统相册与文件导出。
- **TIFF**：16 位无损，仅导出至文件夹（SAF）。
- 已有低精度成片不能靠转换格式恢复高精度细节，请回到来源底片重新扫描。

| 资源 | 图片导出 | 可继续处理的材料 |
| --- | --- | --- |
| 扫描照片 | JPG / PNG / TIFF（按源精度选择） | 经来源入口回到原底片重新扫描 |
| 冲洗底片 | 灯台图（保留极性）或正像投射图（JPG / PNG / TIFF） | 光学底片 NPZ（可传入桌面继续扫描） |
| 曝光胶卷 | 保留的相机 JPEG / DNG 原片导出至文件夹 | 封卷后导出整卷潜影 NPZ（可传入桌面冲洗） |

手机曝光会记录整片的等效分色或银像响应。导出整卷潜影后，桌面可直接用这些记录冲洗。要比较另一套乳剂层序，可以导出原始 JPEG 或 DNG，在桌面重新曝光。[桌面分层操作](DESKTOP_GUIDE.md#coatings)

### 元信息、来源追溯与外观设置

- **元信息与配置详情**：缩略图与观片页展示尺寸、正负性质与时间；点 **••• → 详细信息** 可查看保存时的冻结配方与参数记录（缺失字段如实标“未记录”或“文件时间”，不靠当前设置猜测）。
- **精确来源链**：图像页顶部 **来源** 显示对应胶卷、卷内曝光位置（`画面 01` 等）以及固定短编号的冲洗批次与扫描记录，可直接跳转上游；删除其他结果不会重排编号，完整 ID 见 **详细信息 → 资源标识**。
- **批量导出**：在图库或胶卷库长按多选后点 **导出所选**；底片图片由完整光学源逐行生成，不导出小预览。
- 在 **设置 → 外观与语言** 选择中文、English 或系统语言，也可点 **导入语言包…** 安装社区 JSON。这里还可切换黑橙、象牙白、灰蓝、浅灰四套配色。右上角 **?** 打开当前页面的离线指南。[制作与挂载语言包](../android/TRANSLATING.md)
