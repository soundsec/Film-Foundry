## Android 测试版

当前为 **Android 0.1.0 测试版**，要求 **Android 8.0 或更新系统**。APK尾缀为`arm64-v8a`、`armeabi-v7a`、`x86_64`、`x86`或`universal`；每个都可独立安装，后者包含四种架构。现阶段以 **ARM64 手机**为实机测试范围，其他架构未实测。暂无iOS版本。[源码与编译说明](../android/README.md)

相机权限用于拍摄和实景透射；后台冲洗使用前台服务与通知，旧版Android导出系统相册可能需要存储权限。私有胶卷与底片不等同于系统相册文件；应用未开启系统自动备份，卸载前请主动导出需要保留的资源。

JPEG是常规采集格式。最小RAW支持主要针对未压缩8／16位Bayer DNG；Ultra HDR需要Android 14+、兼容sRGB基图与真实增益图，实际可选格式取决于设备。压缩DNG与广色域P3等尚不完整支持，16位扫描输出仍不等于HDR成片。

## 从装卷到成片

1. **装卷**：在拍摄首页选择材料、135／半格／120规格、张数和胶卷名称，设置相机效果后完成装填。装卷首层保留材料、画幅和张数；命名、搭配、采集精度和倒片在“更多装卷设置”中，收起时显示当前摘要。
2. **拍摄**：进入横向取景器，点击对焦测光、双指缩放，调整EV后按快门。未拍完可退出，下次继续同一卷。
3. **封卷**：从拍摄页小菜单封卷，回到胶卷库。
4. **冲洗**：打开这卷，选冲洗工艺，或进入自由冲洗台配置药液。
5. **观片与扫描**：打开冲洗结果，使用灯台观看或进入扫描，调整风格、亮度、色彩和曲线，点“扫描并保存”。

## 拍摄操控

| 操作 | 用法 |
| --- | --- |
| 手动过片 | 拍摄后快门锁定；点“过片”进入下一格 |
| 多重曝光 | 点“多曝”重新上弦，在当前格继续曝光 |
| 自动过片 | 在相机设置中开启，保存后自动进入下一格；拍摄页可快捷切换 |
| EV与倍率 | 按住按钮片刻后滑动；侧栏上下拨、底栏左右拨，双击复位 |
| 宽幅 | 为135上下加入未曝光遮挡带；未过片也可切换，每次曝光独立保留状态 |
| 镜头与闪光 | 在拍摄页选择设备提供的镜头、倍率和闪光选项 |

机身漏光的形状与片门脏物在装卷前的相机设置里选择；胶卷退化、齿孔和厂印边字在胶卷设置里选择。拍摄中可以调整文字打印。齿孔与边字位于照片外侧，120使用无孔片边。

文字打印支持最多 **24 个大小写英文字母、数字、空格和英文标点**；全角英文自动转半角，不支持中文或表情。空白关闭打印。纯日期使用原来的数字字形，加入字母或其它标点后整串使用 5×7 点阵字形。打印亮度范围 0–200%，100% 为原强度，0% 不添加曝光；四角按钮快速定位，水平／垂直位置滑条可自由微调。横屏拍摄中左侧保留样张，右侧切换“内容样式／亮度位置”。保存影响之后的曝光，已有曝光不变。

相机效果按“漏光／片门／打印”切换，预览固定在上方，并显示已配置的效果。漏光可添加最多 8 个分量，分别调形状、方向和强度；总强度控制整体，每个分量设 0 可单独关闭而保留位置。灰尘、碎屑、毛发、飞虫与打印可组合使用。切换面板不应用或清除参数；保存才用于之后的曝光，取消放弃本次草稿。

颗粒、MTF柔化和光晕在装卷前选择。“自然”保留材料自身的强度，其余档位减弱或加强；颗粒“关闭”同时关闭染料颗粒与银粒。设置只用于新装胶卷，已装卷和已有底片保持原样。新装卷使用层内细颗粒与较粗的染料云，彩色材料的三层纹理部分相关；药液仍会影响颗粒强度、尺度与聚集。

## 冲洗与配方

自动冲洗可直接选择预设。**自由冲洗台**可按顺序组合药液，调整温度、时间、浓度、摇晃时长与强度，尝试反转、交叉冲洗、留银和冲洗事故。

冲洗页默认进入“准备”：选择方案，查看本卷材料、所用工艺、预期底片与实际处理顺序，然后开始。方案按推荐、工艺、药液风格和我的配方分类。“自由冲洗台”保留在准备页主入口；药浴条件、冲洗事故、追加片基漂白、扫描与保存分别从总览进入子页，返回先回准备页。顶部显示这次只保留底片，还是同时生成图库照片；底部保留一个开始按钮。未完成任务可从“更多操作”继续，点击开始时也会先识别原任务。

准备页显示单独设置的药浴数和已开启事故数；完成后显示本批保留的底片、照片数量及查看、扫描、导出入口。

“自由冲洗台”直接展示当前工艺的基础药浴顺序，横向选择一浴查看或编辑。只查看、取消或保存未改动的药浴仍沿用原工艺；真正修改单浴后才转为自由组合。开启自由组合可添加、移动或移除药浴，也可用工艺模板替换草稿。工作台的基础药浴与事故页的追加处理共同组成当前冲洗。

工作台以工序为主页面，共用药液与条件、共用摇晃、共用反应、邻接与 DIR 从工序页继续进入；返回先回工序。选择一浴后，再进入该浴的药液、条件、摇晃与反应设置。每浴可沿用共用条件或单独覆盖。主冲洗页的“共用药浴时长”会应用到未设置独立时长的药浴，并非整套流程总时长。滑轨调节数值，点数值可精确输入。单浴点“完成”只更新工作台草稿，外层点“应用到本次冲洗”才带回准备页；取消外层不应用草稿。独立配方编辑器仍使用“应用配置”。自动工艺的顺序与预期结果由实际工艺解析提供。

“冲洗事故”和“追加片基漂白”是独立分支，复位其中一项不改变另一项。显影不匀、药液污染与乳剂网裂可同时使用，每项分别选择沿用药浴、关闭或指定强度。“全部沿用”保留药浴条件自然产生的事故；“干净冲洗”关闭这三类事故，颗粒及其他材料效果保持原设置。事故调整支持本次会话内 24 步撤销／重做，连续拖动一次算一步；撤销不影响已完成的冲洗或片基漂白。

“手机摇晃记录”可使用陀螺仪记录摇晃，也可手动输入。每次冲洗形成独立批次，同一卷可以尝试多套配方。

“扫描与保存”决定是否在冲洗后自动扫描照片并存入软件图库；关闭后只保留冲洗底片，之后可再扫描。扫描参数填写有误时，本次仍完成冲洗并保留底片；修正参数后，可从底片重新扫描。

片基漂白会显示当前工艺的实际设置，手动关闭会明确停用；“沿用工艺”可恢复预设。扫描反相默认随最终底片的正负性；负像默认去片基并反相，透明中性正像默认两项都关闭，带明显色罩的正像默认去色罩而不反相。系统按最终底片设置初始开关，用户可分别开启或关闭，点“恢复自动匹配”重新采用系统判断。每次选择另一张底片重新自动匹配；同片切换或恢复扫描风格保留这两个开关，旧风格中的反相和去片基字段不作为风格参数应用。去片基只校正扫描参考，不会漂白或改变底片。

彩片使用黑白工艺时，输出按银像标记，片基与可能残留的卤化银仍保留；负片正冲、反转片负冲的正负性按有序药浴的实际响应决定。

材料名称标明“彩色／黑白、负片／反转片”；冲洗选择标为工艺，默认“自动匹配胶卷”。冲洗页显示“本卷材料 → 工艺 → 预期结果”。当前无染料层的黑白材料使用完整彩色工艺时，银漂白可能清除影像；页面会提示，并可一键改用彩色负片工艺留银。工艺仍可自由选择。

材料、药液与扫描配置在设置页独立保存。用 **FFC2 分享码**复制或导入配方；装好的胶卷和已有冲洗任务沿用各自保存的配置。

## 观片与扫描

| 方式 | 呈现 |
| --- | --- |
| 灯台 | 查看底片原本的正负像，点“灯光”调亮度和色温 |
| 实景透射 | 将透明底片叠在实时相机背景上，支持放大、拖动与复位 |
| 正像投射 | 将底片解释为正像观看 |
| 扫描 | 选择成片风格，调亮度、色彩及影调／RGB曲线，保存照片 |

胶卷的冲洗批次里可“调整扫描参数”，扫描单张或按当前参数扫描本批。已保存的照片也可找到来源底片重新扫描。

扫描预览调节灯光时会复用同片透射读数，保留原有设备响应、裁切与调色顺序。首次读取底片仍需等待；较慢时显示等待指示，快速更新不闪进度圈。

切到后台再返回时，已完成的预览与保存参数会保留；未完成的预览按自动刷新开关恢复。关闭自动刷新时，点刷新后再保存。

扫描页的保存与整批扫描沿用当前成功预览的参数；修改参数或刷新时，等待新预览完成后再保存。按住预览右上角的 ◧ 对照本次进入时的首次成功预览，松手回到当前效果；对照不改参数，也不重新计算。

扫描页上方固定预览，预览下方固定“风格”入口，先选择扫描预设，再调其参数。下方工具顺序为：底片（去片基／反相）→光源（曝光／色温）→明暗（扫描增益／对比度）→归一化→色彩→曲线→输出→更多。风格是参数的起点，不是后续处理步骤；选择或恢复风格只载入风格参数，保留独立的去片基、反相与输出设置。新版手机扫描在中性曝光下完成片基与黑白场定标，再应用光源曝光：反相开启时 EV 降低变亮，关闭时 EV 升高变亮。色温仍用于透射采集，「明暗」中的扫描增益始终同向调亮。旧照片继续编辑与旧任务保留原执行方式；从底片进入的新扫描使用新版。滑轨调节参数，点数值可精确输入或沿用预设；“归一化”可切换强度、黑点和白点，用于匹配黑白场；原画面已接近目标范围时，变化可能较小。扫描时收起品牌大标题与四页导航，顶部为返回、当前画面、撤销／重做和保存。点预览左上角的展开图标可展开看图；刷新、本批扫描和系统相册选项在“输出”，批量执行仍先确认。配置另存和设备定义在“更多”。设置里的配方页集中材料、药液和扫描预设，存储与缓存放在“后置处理”。

在已保存照片的菜单中，“继续调整这张照片”从本照片的冻结参数和原扫描实现开始；“从来源底片开始扫描”进入独立的底片编辑会话，不串用照片草稿。来源底片缺失时保留提示；保存配置无法读取时会报错，不改用当前草稿。编辑会话只存参数，进程内最多保留八个来源，各有最多24步撤销；重启后可再次从照片保存的配置开始。

一次滑轨或曲线拖动、一次组复位各算一步撤销。风格面板可连续试选，看上方预览和本片效果缩略图；“完成”接受这一轮，“取消”恢复打开面板前的状态，也保留原有重做。风格和材料选择均支持收藏、最近使用；材料列表为标准冲洗的合成示意样张，详细搭配预览入口仍保留。缩略图仅作选择参考，不作为底片或正式扫描输入。

单张点“保存”直接保存到软件图库，完成后留在编辑会话，可查看成片、继续调整，或在本批有下一张时继续。同参数的已有版本会明确提示复用；之前版本保留。“输出”可开启同时导出到系统相册，申请权限后才执行。

预览右上角的直方图按钮可开关角落叠层，曲线图仍显示当前通道的分布。饱和度位于「色彩」，独立对比度位于「明暗」，不改写曲线。新默认负片扫描先以 sigmoid 收住高光，再执行归一化，降低归一化不再混回无界读数。旧照片原参数和自定义配方不会自动改写。统计来自当前显示的整张 sRGB 预览成片，包含已有调色，不是 RAW 或曲线输入的直方图，也不代表原底片全分辨率统计。修改后等待新预览时标记“待刷新”，按住初始预览对照时切换对应统计。

曲线直接在预览下方调节，黑白、红、绿、蓝圆点切换通道；双击曲线加点，拖动调整，点坐标可精确输入。“输出”显示底片与预计成片尺寸。风格入口显示“预设名”；调整增益、色彩、曲线等风格参数后显示“预设名 · 自定义”，长按可查看改动项目。仅切换去片基或反相不改变风格标记。

“后置处理 → 计算与加速”提供 **GPU协同计算（自动择优）**，新设置默认开启，已有选择保留，下次任务生效。可参与输入线性化、密度到透射、光谱积分与扫描输出联合计算；按包含传输的耗时选择CPU或GPU，校验或运行失败回退CPU。全图统计、显影与预览仍由CPU执行，JPEG保持整幅参考解码，后续计算按内存分段。光谱模式保留全部波长，不靠减少波长换取速度。硬件加速自测使用合成数据，不写图库、不更改加速开关，计算块成绩不等于整张冲洗耗时；最近运行记录显示实际后端。

潜影与底片保存使用快速无损压缩，像素和材料数据不变，文件可能稍大。“最近运行记录”显示最近任务已执行部分的累计耗时，包括参数与空间准备、材料计算、中间写入、压缩提交；材料计算包含行读取，数值不是单张快门时间。

## 胶卷库与图库

底部四页分别为拍摄、胶卷库、图库、设置。胶卷库按卷组织所有冲洗批次；图库提供照片／底片网格，照片支持连续滑动和缩放，放大后拖到左右边缘再继续滑动即可翻页，长按可批量勾选管理。照片清晰图按内存预算加载，预算允许时保留原尺寸用于查看细节。

布局按钮依次切换三列、五列与列表；两种网格主要区别是图片大小，列表展示详细信息。内容筛选与排序支持创建时间／文件大小／卷名、升降序、指定胶卷、仅收藏及评级比较（>、<、≥、≤，0为未评级），并设置翻页或连续滑动。大图页面的五颗星与爱心分别控制评级、收藏；胶卷页的冲洗批次也可长按管理。缩略图会衔接高清图，加载期间保留已有预览。

| 资源 | 管理方式 | 后续用途 |
| --- | --- | --- |
| 曝光结果 | 按整卷管理 | 再次冲洗 |
| 冲洗底片 | 单张或批量管理 | 观片、重新扫描 |
| 扫描照片 | 单张或批量管理 | 浏览、导出 |

三层独立保存。删除某层后，其他层仍保留；来源已删时显示缺失提示。

底片小预览使用平均采样抑制锯齿，放大时按内存预算后台逐行加载清晰画面，过程中仍可切换底片。原光学材料不变。 已生成的灯台／投射图会保留为独立显示缓存，再次打开可直接读取；改变灯光后重新生成。首次打开尚无缓存的大底片仍需读取完整材料。可在“后置处理→显示缓存”清理，底片和照片会保留。

参数旁的 **↺** 恢复该项预设或继承值。扫描页各组的 ↺ 只恢复该组，保留当前风格和其他调整；“预设曲线”恢复风格自带的影调与 RGB 曲线，曲线工具原有的通道 ↺ 仍表示恢复直线。独立材料、扫描定义和自由冲洗台的整组 ↺ 回到打开时的草稿，不改已保存的材料或任务。灯台复位为 0 EV／5500 K。拍摄页继续使用原有双击复位。

## 保存与导出

扫描页顶部提供保存入口；“输出”内设置格式、质量、尺寸、系统相册导出和本批扫描，沿用当前成功预览的参数。冲洗与整批执行前查看确认信息。冲洗时需开启自动扫描才能同时导出照片；只冲洗则保留底片，之后可扫描。

JPG为8位有损，质量分低／中／高三档（40／70／100）；PNG支持8／16位，TIFF为16位无损。自动扫描也使用“扫描与保存”里的输出设置。导出时需明确选择格式和位置：系统相册接收JPG／PNG，TIFF保存到文件夹。已有JPG未旋转时复制原件；转换或旋转才重新编码，质量不高于原JPG记录值。已有低精度成片不能导出成更高精度来恢复细节，应从底片重新扫描。

| 资源 | 图片导出 | 继续处理的材料 |
| --- | --- | --- |
| 扫描照片 | 按源格式／位深选择兼容的JPG、PNG或TIFF；TIFF仅导出文件 | 从来源入口找回底片，重扫可重新选择输出精度 |
| 冲洗底片 | 灯台观片（保留极性）或正像投射；可选JPG／PNG／TIFF，TIFF仅导出文件 | 光学底片 NPZ，供桌面继续观察与扫描 |
| 曝光胶卷 | 保留的相机 JPEG／DNG 原片导出到文件夹 | 封卷后导出整卷潜影 NPZ，供桌面继续冲洗 |

图库缩略图与观片页显示尺寸、性质和时间；照片标明来源底片的正负性质，胶卷标明材料性质，预计尺寸会注明“预计”。照片／底片在“••• → 详细信息”查看保存时的配方与记录；胶卷详情也有“详细信息”，可查看装卷材料、拍摄与默认冲扫配置。冲洗结果使用实际介质极性。旧记录缺少创建时间时，底片会注明“文件时间”；无法追溯的字段显示未记录，不按胶卷名称或当前参数猜测。

图像页顶部的“来源”展示对应胶卷、画面、冲洗批次和扫描记录，可直接打开来源胶卷、冲洗批次或底片。“画面 01”表示卷内曝光位置，不是当前图库的排序；同一画面的不同冲洗、扫描结果分别保留固定短编号，不随其他结果删除而重排。完整资源标识在“详细信息→资源标识”查看。

来源分为可用、已删除／未收录、文件缺失。缺少来源时当前图像仍可独立查看与导出；不自动选择同一画面的另一张底片替代。新保存照片同时保留来源底片的实际材料／冲洗配置；旧照片缺少来源与记录时显示“未记录”。

图库和胶卷库长按可多选，再点“导出所选”。底片图片从完整光学资源生成，不使用小预览；材料和原片只导出为文件。尚未形成的潜影在导出时准备，可能需要等待。导出不会删除软件内资源；换机或卸载前先导出需要保留的文件。

设置页可切换中文／English、深色／Light外观。页面右上角“?”直接打开当前步骤的图文指南，也可切换拍摄、冲洗、观片与扫描、资源保留和浏览整理主题；详细操作按需展开，返回后继续原页面。
