## 0.4.0 Alpha 发行汇总 / Android 0.1.0 测试版

2026-11-02 整理。桌面显示版本为 **0.4.0**，手机使用独立版本号 **0.1.0**（内部版本码 34）。

### 桌面维护

- 扫描分块共享不可变的全图校准与输出曲线参数，连续完成归一化、sRGB 编码与亮度曲线，保留原 CPU 公式与参考路径。
- 8 位输出防色带替换为明确署名的 `lowbias32`，保持确定性与分块一致性。
- Windows 打包限制 DLL 搜索范围至所选 Python 环境与系统目录，并随包收集完整原生依赖与许可清单。

### Android 测试版 · 0.1.0

- **拍摄与胶卷**：完整装卷（12 / 24 / 36 张）、手动/自动过片、多重曝光、135 宽幅、横屏文字打印、封卷与三层独立资源管理（原片/潜影、底片、照片）；支持 JPEG、未压缩 8 / 16 位 Bayer DNG 与兼容 Ultra HDR。
- **冲洗与扫描**：冲洗准备页汇总工艺与工序顺序，支持自由冲洗台、只留底片或自动扫描；后台有界并发与可选 OpenGL ES 协同计算（精度/耗时校验合格才启用，失败回退 CPU）。
- **图库与导出**：三列/五列/列表视图、评分收藏独立筛选排序；支持 JPG（低/中/高）、PNG（8 / 16 位）与文件导出 TIFF（16 位）。
- **安装与签名**：要求 Android 8.0+，提供 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64` 与 `universal` APK（实机测试聚焦 ARM64）；采用独立发布签名，应用内内置完整第三方许可正文。

## 0.3.1 Alpha 与 0.3 系列

v0.3.1 为基于 v0.3.0 的稳定性、兼容性与通用性能维护版本，奠定了当前统一银盐材料模型与只读扫描架构的基础：

- **统一银盐形成与只读扫描**：彩色/黑白负片与反转片共享材料池与有序算子，极性由工序顺序产生；扫描统一读取最终介质派生的 `optical_density_rgb`，用户独立控制去片基与反相，扫描绝不回写冲洗结果。
- **分块一致性与通用优化**：扫描与材料分块共享全图冻结校准，消除分块接缝；收紧大图数组生命周期、缓冲复用与原子多文件提交。
- **输出与稳定性**：支持 `.darkroom_negative.npz` / `.darkroom_positive.npz`、16-bit scanner raw TIFF、透明介质与 Layer Pack；补齐 EXIF 方向规范化、运行清单记录及异常输入拦截。
- **历史版本兼容说明**：旧 `half_frame_darkroom` 包名与命令已移除；推荐使用拆分后的 `film/`、`develop/`、`scanner/` 预设目录（旧完整 JSON 仍可读）；`legacy_density` 仅作显式回归对照保留。
