## 0.4.0 Alpha 发行汇总 / Android 0.1.0 测试版

2026-11-02 整理，包含本次发布准备修订。桌面显示版本仍为 **0.4.0**；手机使用独立版本号 **0.1.0**（内部版本码 34），不是 Android 0.4.0。本文为本次发行准备说明，不表示已上传正式发行包。

### 桌面维护

- 扫描分块共享不可变的全图校准和输出曲线参数；归一化、sRGB 编码、亮度曲线在每个分块内连续完成，保留原 CPU 公式、精度与参考执行路径。
- 这一步是后续计算后端的基础，桌面目前仍使用 CPU；尚未启用 GPU，也不改变完整质量模式或光谱精度。
- 为消除旧坐标表达式的来源未决项，8位输出防色带改用有明确上游授权的lowbias32。噪声强度、平滑区遮罩、确定性和分块一致性保留，具体抖动像素会不同；关闭防色带、16位输出和冲洗形成结果不受该替换影响。
- Windows打包限制DLL搜索范围为所选Python环境与系统目录，避免从其他工具的PATH混入同名原生库；新增实际原生文件及匹配依赖包的通知清单。

### Android 测试版 · 0.1.0

#### 拍摄与胶卷

- 新增 Android 相机工作流：装入 12／24／36 张胶卷，手动／自动过片、多重曝光、封卷、冲洗、观片及扫描。胶卷与冲洗批次分开保存，同一卷可以反复形成不同结果。
- 拍摄保留采集原片，部分潜影形成计算延后到处理阶段；首次冲洗的等待可能包含潜影形成，不能与只冲洗已有潜影的计时直接比较。

- 照片浏览从缩略图衔接高清图，避免清屏闪黑；改善黑色浏览界面的系统栏和安全区配色。
- 拍摄中的文字打印使用横屏双栏，支持最多 24 个大小写英文字母、数字及英文标点；纯日期保留原字形，新增亮度和四角／自定义位置。
- 自动过片移入相机设置，拍摄页保留快捷切换；135 宽幅可在未过片时切换，每次曝光分别保留遮幅状态。
- JPEG 为常规采集入口。RAW／Ultra HDR 提供最小支持：主要为未压缩 8／16 位 Bayer DNG，以及 Android 14+ 上带真实增益图的兼容 sRGB Ultra HDR；不宣称完整支持压缩 DNG、广色域 P3 或 HDR 成片输出。

#### 冲洗、扫描与计算

- 冲洗准备页集中选择工艺、药浴顺序与资源保留；可只保存底片，或冲洗后自动扫描，并设置扫描格式、位深及 JPG 质量。胶卷页长按已有冲洗批次即可管理。
- 后台任务与有界并发减少处理对界面操作的阻塞；实际并发能力仍受设备内存、相机和系统调度约束，不承诺所有操作同时无等待。
- GPU 协同覆盖已实现的矩阵／光谱、密度转透射及扫描输出步骤；先验证精度和耗时，满足条件才选用 OpenGL ES 计算，不可用或失败时回退 CPU。设置提供硬件自动测试；Vulkan 尚未实现，完整显影也没有全部迁到 GPU。
- 扫描只读冲洗后的介质，支持去片基、反相、光源、影调／RGB 曲线与原尺寸或指定长边输出。GPU 加速不会自动关闭光谱或切换简化质量模式。

#### 图库与导出

- 图库在三列、五列和列表间切换，支持翻页或连续浏览；长按进入管理，评分与收藏独立设置。
- 内容筛选包含胶卷、收藏与评级比较条件，可按时间、文件大小或卷名排序。
- JPG 简化为低／中／高三档（40／70／100）；另支持 PNG 8／16 位和文件导出的 TIFF 16 位。系统相册接收 JPG／PNG；从低精度成片无法恢复高精度，需回到底片重新扫描。
- 原片／潜影、冲洗底片与扫描成片分别保留；卸载或换机前需要主动导出重要内容，不依赖 Android 自动备份。

#### 安装、源码与当前边界

- 手机显示版本统一为 0.1.0，保留从旧测试版升级所需的内部版本码；覆盖安装还要求应用 ID 和签名一致。
- Android 8.0+，提供 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64` 和 `universal` APK；当前实机验证集中在 ARM64，其他 ABI 已构建但未实机验证。暂无 iOS 版本。
- Android 五个模块的源码、Gradle wrapper、合成测试夹具和设备检查工具已纳入本次公开源码准备区；不包含 SDK 路径、签名私钥、设备日志或私人照片。
- 手机与桌面共享介质格式和 FFC2 配方，使用独立计算实现，不保证逐像素一致；桌面目前仍为 CPU 路径。
- 本次新增独立发布密钥签名的release APK，旧测试包使用调试签名，两者不能直接覆盖安装；切换前需导出重要内容。Windows Alpha便携包仍未作代码签名。
- 补齐Android实际运行时依赖清单、原始许可和CameraX所用libyuv通知；“关于软件”可直接阅读许可，release构建检查依赖声明是否与当前解析版本一致。密钥与密码不进入公开源码。

## 0.4.0 Alpha · 桌面版

2026-10-26 首版主要变更，相对于0.3.1；后续维护见上方发行汇总。

### 桌面工作台

- 六页工作台：任务与输出、胶卷与拍摄、冲洗、观察与调色、计算设置、独立配置。
- 常用参数前置，低频参数分组折叠；预设支持搜索和分类筛选。
- 材料、药浴和扫描保持独立编辑器，统一为Film Foundry组件。
- 中文／English、深色／Light外观；切换语言保留曲线草稿与页面位置。
- 角落“关于”入口展示版本、作者和仓库。

### 材料与创作

- 完整流程、只曝光、冲洗潜影、只冲洗、只扫描五种工作方式。
- 彩色／黑白负片、反转片与交叉冲洗共享材料程序，支持独立去色罩步骤。
- 乳剂MTF、密度与金属银颗粒、光晕、材料退化和冲洗事故。
- 相机漏光、片门脏物和冲洗批次分别保存瑕疵身份。
- 日常12种材料、5种冲洗程序、10种扫描解释，另可展开风格与专门药浴。
- Smits七基曝光升维，以及光谱材料／观察档案编辑。
- 影调／RGB曲线直接加点、拖动与删除，设备响应曲线位于专家控制。

### 预览与任务

- 自动预览合并连续调参，也可手动刷新；支持缩放、拖动和100%查看。
- 扫描调整复用已形成介质，谱小表预计算、分块积分和缓冲复用减少重复计算。
- 批次显示阶段与输出目录，支持取消和恢复未完成任务。
- 必填路径检查与数值控件防误滚。

### 文件与兼容

- Python入口统一为`film_foundry`，历史介质、预设键、会话和FFC2继续可读。
- 修复旧式Layer Pack缺少可选光谱字段时的导出错误。
- 视频逐帧导入为材料母带，解码使用可选PyAV。
- 桌面可读取手机介质；本次公开源码同时包含 Android 0.1.0，见上方手机版说明。

## 0.3.1 Alpha 与 0.3 系列

v0.3.1 是基于 v0.3.0 的稳定性、兼容性和通用性能维护版本。它面向创作和可调节的材料过程，不做物理复刻，也不承诺对应某一款商业胶卷或扫描仪。

### v0.3.1 维护更新

- 收紧统一材料状态转换：首次显影会同步消耗剩余可显影份额，反转激活、部分显影、漂白和定影继续遵守同一材料池语义。
- 最终扫描统一读取由冲洗后介质派生的 RGB 总光学密度；染料层、金属银、残余银盐、片基和附加层保留各自形成来源，扫描不会反写介质。
- 负片与正片共享透射采集。去片基与反相由用户分别控制；内部介质优先使用已知片基，外部介质可使用明确边框样本或整图高透射包络回退。
- 扫描分块共享同一组全图片基、曝光、黑白点和归一化参数，避免逐块自动估计造成接缝；材料、颗粒、事故和扫描分块增加了网格一致性回归。
- 改善颗粒、染料云、高光光晕、残银和冲洗事故的阶段归属与极端参数稳定性，并保持固定种子的可重复输出。
- 收紧大图处理中的数组生命周期、分块保存和临时缓冲复用；这些通用优化不依赖特定硬件，也不改变质量模式的算子和输出语义。
- 完整流程、只冲洗和只扫描现在会在运行清单中记录逐项成功、失败、输出位置和耗时；记录采用内存汇总与批次末单次写入，不参与图像计算。
- 修复部分竖向图片的 EXIF 方向不一致、重复输出覆盖、批次故障隔离，以及 Windows 便携版在特殊目录或中文路径下的 Tcl/Tk 启动问题。

### v0.3 系列主要能力

#### 统一的银盐形成流程

- 彩色/黑白负片与彩色/黑白反转片共享材料池和有序处理算子。
- 负片、正片、反转和漂白旁路由材料实际经历的步骤产生，不再依赖末端数学反相伪造。
- 显影后的潜影激活比例会随剩余卤化银同步更新，重复显影与部分反转激活遵守同一材料守恒关系。
- 统一彩色流程把最终 RGB 光学密度作为扫描权威输入；旧 CMY 母版继续保留给兼容文件、制版和分层导出。
- 支持彩负反转冲洗、反转片负片冲洗及材料—工艺兼容参数。
- 迫冲/减冲、显影时间与温度、搅动、药水疲劳、定影不足、残银、漏光、显影不均、材料退化和实验性镀银等控制进入正式冲洗链路。

#### 冲洗与扫描分离

- 冲洗保存负片或反转正片介质；扫描只读取最终介质，不修改冲洗母版。
- 负片与正片共用透射光源和传感器采集；用户可独立控制片基/色罩去除、反相和可选通道补偿。
- 项目内部使用冲洗后已知片基；外部 raw 依次回退到明确边框样本和画面百分位估计。
- 材料极性只提供建议；保留片基且不反相可直接输出灯台上的负片翻拍或正片观看结果。
- 可选片基参考边框只扩展扫描观察画布，不会写回冲洗母版或 RGB 光学母版。

#### 材料与输出

- 增加彩色和黑白反转材料、正片灯台预设及更清晰的中英文预设名称。
- 支持负片/正片 NPZ、scanner/light-table raw、透明介质、16-bit transmission TIFF、制版辅助层和 Layer Pack。
- Layer Pack 是包含介质、预览、raw、透明介质、制版层和 manifest 的完整集合，不是重复的第三套分层定义。
- 主 GUI 的完整流程与只冲洗流程按每次执行创建时间运行目录并保存完整设置快照；只扫描结果默认回到介质目录上一级，并以扫描时间区分不同代次，避免重复运行覆盖旧结果。

#### 性能与大图

- `quality`：正式尺寸和完整流程。
- `scaled_fast`：缩小输入尺寸，用于快速试色。
- `reduced_fast`：保留输出尺寸，只降低已声明的内部细节计算。
- 默认舒适区约为 30MP；更高分辨率仍可尝试，但属于 best-effort，并取决于内存、导出内容和处理配置。
- 增加材料形成、扫描和保存分块、受限混合精度、派生数据缓存、资源预检及原子多文件提交。

#### 稳定性

- 扫描前后材料母版保持不变，完整流程与分段流程具有系统不变量测试。
- 损坏 NPZ、非法 metadata、NaN/Infinity 和批处理内部同名冲突会明确失败；GUI 的不同执行代次由运行目录或时间后缀隔离。
- JPEG/PNG 的八种 EXIF Orientation 和 TIFF 方向统一在输入边界落实到像素，避免部分竖图输出为横图。
- 当前自动化测试覆盖材料池、冲洗、扫描、输出、GUI preset、性能边界和文件回滚。

### 兼容性

- 旧 Python 包名和 `half-frame-darkroom` 命令不再提供。旧的完整 JSON 配置仍可读取。
- 拆分后的 film/develop/scanner preset 是推荐格式；旧完整 JSON 配置仍可读取。
- `legacy_density` 只作为显式诊断/回归入口保留，不再是默认形成路径。
- 建议在升级前备份自定义 preset 与重要电子介质文件。

### 该版本限制

- 暂不直接读取 DNG 或相机私有 RAW；建议先导出高质量 TIFF、PNG 或 JPEG。
- 正片/反转流程仍标为 experimental；外部实物与实验室验证尚未完成。
- 超过 30MP 的工作负载不能保证在所有电脑上顺畅运行。
- Windows 便携包没有代码签名，可能触发 SmartScreen 提示。
- 该版本旧窗口在部分 Windows 上拖动复杂界面时可能发黏，但不会改变处理结果。当前桌面界面以项目说明为准。
