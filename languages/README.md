# Film Foundry language packs

Copy a UTF-8 dictionary here using its language code as the filename, for example `fr_CA.json`. Reopen desktop Settings and select its display name under Appearance & Layout.

将 UTF-8 翻译包放在此目录，文件名与包内的 `code` 一致。重新打开桌面全局设置，在「外观与布局」选择语言。Android 用户可在手机设置中直接导入同一格式的文件。
